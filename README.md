
программа
1. Находит установленный Black Myth: Wukong Benchmark Tool.
2. Сохраняет исходные настройки.
3. Применяет настройки CPU-теста.
4. Запускает Benchmark Tool.
5. Ждёт завершения.
6. Применяет настройки GPU-теста.
7. Снова запускает Benchmark Tool.
8. Сохраняет характеристики компьютера и FPS в `Results/report.txt`.
9. Возвращает исходные настройки пользователя.


 CPU-тест
- 1280x720
- Resolution Scale 50%
- большинство графических параметров Low
- View Distance High
- Ray Tracing Off

Низкое разрешение и низкое качество графики уменьшают влияние видеокарты. Поэтому ограничение чаще смещается в сторону CPU.

 GPU-тест
- 2560x1440
- Resolution Scale 100%
- графика High
- Ray Tracing Off

Высокое разрешение и высокое качество графики заметно увеличивают нагрузку на GPU.

Ray Tracing выключен, чтобы один и тот же проект можно было запускать как на RTX, так и на видеокартах без аппаратной трассировки лучей.

Инструкция к запуску!!

Нужны:
- Windows 10/11
- .NET 8 SDK
- Steam
- установленный Black Myth: Wukong Benchmark Tool
- PresentMon.exe рядом с собранным `.exe` программы для автоматического измерения FPS

Если Steam установлен не в стандартной папке, измените `gameFolder` в начале `Program.cs`.
Запуск
Откройте папку проекта в Visual Studio и нажмите Run.

Или в терминале:

    dotnet restore
    dotnet run

Результат появится в:

    Results/report.txt


Benchmark Tool имеет графический интерфейс и официально запускается через `b1_benchmark.exe`.
Проект активирует его окно и отправляет Enter для запуска теста. Если в вашей версии интерфейса кнопка Start Benchmark не выбрана по умолчанию, нужно один раз проверить положение фокуса в окне.

FPS считывается через PresentMon. Сам Benchmark Tool всё равно является программой, которая выполняет тест; PresentMon используется только для автоматической записи кадров в CSV.
